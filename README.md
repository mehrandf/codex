# مدیریت لینک‌های شخصی

این پروژه یک اسکریپت ساده مبتنی بر PHP است که به شما اجازه می‌دهد مجموعه‌ای از لینک‌های شخصی خود را در یک صفحه زیبا و واکنش‌گرا نمایش دهید و از طریق یک پنل مدیریتی فارسی آن‌ها را مدیریت کنید.

## ویژگی‌ها
- رابط کاربری فارسی و راست‌به‌چپ با فونت استاندارد «وزیرمتن»
- صفحه عمومی با دکمه‌های سفارشی برای شبکه‌های اجتماعی و وب‌سایت‌ها
- امکان افزودن، ویرایش و حذف لینک‌ها از طریق پنل مدیریت
- پشتیبانی از تعیین نوع لینک (Follow, NoFollow, Redirect 301)
- ذخیره‌سازی داده‌ها در فایل JSON بدون نیاز به پایگاه داده
- استفاده از کتابخانه آیکون Font Awesome برای انتخاب آیکون دلخواه

## پیش‌نیازها
- وب‌سرور سازگار با PHP (نسخه 8 یا بالاتر توصیه می‌شود)
- فعال بودن قابلیت نوشتن (write) در پوشه `data` جهت ذخیره لینک‌ها

## نحوه راه‌اندازی
1. تمام فایل‌های پروژه را در هاست اشتراکی یا فضای میزبانی خود آپلود کنید.
2. مطمئن شوید پوشه `data` قابلیت نوشتن توسط وب‌سرور را دارد. در صورت نیاز سطح دسترسی آن را به 775 یا 755 تغییر دهید.
3. در مرورگر خود آدرس `index.php` را برای مشاهده صفحه عمومی و `admin.php` را برای ورود به پنل مدیریت باز کنید.
4. نام کاربری و رمز عبور پیش‌فرض:
   - نام کاربری: `mehrandfme`
   - رمز عبور: `Mm@123qweasd`
5. پس از ورود به پنل مدیریت، می‌توانید لینک‌های جدید بسازید یا لینک‌های موجود را ویرایش/حذف کنید.

> **نکته:** برای استفاده از ریدایرکت 301، در زمان ایجاد یا ویرایش لینک نوع «ریدایرکت 301» را انتخاب کنید. در این حالت کاربران ابتدا به فایل `redirect.php` هدایت می‌شوند و سپس با وضعیت 301 به مقصد اصلی منتقل خواهند شد.

## ساخت فایل زیپ
برای دریافت خروجی زیپ از پروژه، می‌توانید در خط فرمان از دستور زیر استفاده کنید:

```bash
tar -czf link-manager.tar.gz .
```

یا در محیط‌های گرافیکی با انتخاب همه فایل‌ها و گزینه فشرده‌سازی، یک فایل ZIP ایجاد کنید.

## ساختار پوشه‌ها
```
.
├── admin.php           # پنل مدیریت لینک‌ها
├── config.php          # تنظیمات کلی شامل اطلاعات ورود و مسیر فایل داده
├── functions.php       # توابع مشترک برای خواندن/نوشتن داده‌ها
├── index.php           # صفحه عمومی نمایش لینک‌ها
├── redirect.php        # اسکریپت ریدایرکت 301
├── assets/
│   ├── css/style.css   # استایل‌های اصلی رابط کاربری
│   └── images/avatar-placeholder.svg
├── data/links.json     # فایل JSON جهت ذخیره لینک‌ها
└── README.md           # همین فایل راهنما
```

با خیال راحت ظاهر و محتوای صفحات را مطابق سلیقه خود ویرایش کنید.
